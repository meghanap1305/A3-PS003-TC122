Key insights

    Car movement is a visual mapping of the selected model feature (not a literal vehicle-speed measurement). The model predicts 12 future five-minute steps; use the horizon selector to inspect +5 to +60 minutes. Colour = client (A blue, B purple, C teal). Shape = communication: circles are model updates, returning green circles are global-model broadcasts, squares are raw readings in the centralized view. Car colour = mapped congestion level. IID sensor lanes are replay buckets, not actual sensor ownership.
